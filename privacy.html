Privacy Policy

  • What is read: public profile info (username, follower count) and per-video statistics (views, likes, comments, shares) of the owner's own account, through each platform's official API with the owner's authorization.
  • Where it is stored: only in a local database on the owner's computer. Nothing is uploaded to any server run by the app.
  • Sharing: the data is never sold, shared with third parties, or used for advertising.
  • Other people's data: the app does not collect data about other users or viewers.
  • Deletion: revoking the app's access on the platform stops all collection; deleting the local database removes all stored data.
